**Summary** subscriptions help you regularly receive a short AI-generated summary of new messages in a selected Telegram chat or channel. Instead of rereading long discussions every day, you configure a subscription once, and CoTel sends you a scheduled summary.

This subscription type is useful when you do not need a single alert, but want regular understanding of the bigger picture: what was discussed, which topics repeated, what decisions were made, what problems appeared, and which messages are worth reading manually.

<Info>
  A Summary subscription works best when you define the answer structure in advance: for example, “main topics”, “decisions”, “tasks”, “problems”, “useful links”, or “important messages”.
</Info>

## How each example is structured

Each scenario below shows:

- **Subscription name** — how you can name it in CoTel
- **Subscription type** — Digest / Summary
- **Where to use it** — the suitable type of chat or channel
- **Frequency** — a reasonable interval for receiving the summary
- **Example query** — what to write in the query field
- **What you will receive** — what kind of result you will get in Telegram

## How to write good queries for Summary subscriptions

A good digest query usually defines not only the topic, but also the structure of the future summary. This helps CoTel return a more convenient and predictable result.

A good query may include:

1. **Main goal** — what exactly needs to be summarized
2. **Answer structure** — topics, decisions, tasks, problems, links, recommendations
3. **Priorities** — what should be considered important
4. **Exclusions** — what can be left out
5. **Limitations** — for example, do not give professional advice, only summarize the discussion

<AccordionGroup>
  <Accordion title="Too broad request">
    “Create a digest.”

    This request may return a result that is too general and lacks a clear structure.
  </Accordion>

  <Accordion title="More effective request">
    “Create a daily summary of discussions: main topics, decisions, tasks, problems, useful links, and messages worth reading manually.”

    This request gives CoTel a clear answer format and helps produce a more useful digest.
  </Accordion>
</AccordionGroup>

## When to choose Summary and when to choose Events

| Task | Better choice |
| --- | --- |
| Receive a notification when a specific listing, vacancy, or mention appears | Events |
| Receive a short daily summary of a large chat | Summary |
| Track user errors or urgent messages | Events |
| Regularly understand what was discussed in a channel or community | Summary |
| Search for a specific product, apartment, ticket, or job | Events |
| Receive an overview of news, author ideas, or work discussions | Summary |

<Note>
  CoTel is at an early stage of development. The current version of subscriptions is focused on two main types: Events and Digests. Subscription functionality will be expanded based on user feedback and real use cases.
</Note>
