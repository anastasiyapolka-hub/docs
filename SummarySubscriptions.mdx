**Summary** subscriptions help you regularly receive a short AI-generated summary of new messages in a selected Telegram chat or channel. Instead of rereading long discussions every day, you configure the subscription once, and CoTel sends you a scheduled summary.

This subscription type is useful when you do not need a single specific signal, but want a regular understanding of the bigger picture: what was discussed, which topics repeated, what decisions were made, what problems appeared, and which messages are worth reading manually.

<Info>
  A Summary subscription works best when you define the response structure in advance: for example, “main topics”, “decisions”, “tasks”, “problems”, “useful links”, or “important messages”.
</Info>

## How the examples are structured

Each scenario below shows:

- **Subscription name** — what you can call it in CoTel
- **Subscription type** — Digest / Summary
- **Where to use it** — suitable type of chat or channel
- **Frequency** — a reasonable interval for receiving the summary
- **Example request** — what to write in the request field
- **What you will receive** — what result you will get in Telegram

## How to write good requests for Summary subscriptions

A good digest request usually defines not only the topic, but also the structure of the future summary. This helps CoTel return a more convenient and predictable result.

A good request can include:

1. **Main goal** — what exactly should be summarized
2. **Response structure** — topics, decisions, tasks, problems, links, recommendations
3. **Priorities** — what should be considered important
4. **Exclusions** — what can be left out
5. **Limitations** — for example, not giving professional advice and only summarizing the discussion

<AccordionGroup>
  <Accordion title="Too broad request">
    “Make a digest.”

    This request may return a result that is too general and lacks a clear structure.
  </Accordion>

  <Accordion title="More effective request">
    “Create a daily summary of discussions: main topics, decisions, tasks, problems, useful links, and messages worth reading manually.”

    This request gives CoTel a clear response format and helps produce a more useful digest.
  </Accordion>
</AccordionGroup>

## When to choose Summary and when to choose Events

| Task | Better choice |
| --- | --- |
| Receive a notification when a specific announcement, job posting, or mention appears | Events |
| Get a short daily summary of a large chat | Summary |
| Track user errors or urgent messages | Events |
| Regularly understand what was discussed in a channel or community | Summary |
| Search for a specific product, apartment, ticket, or job | Events |
| Receive an overview of news, author ideas, or work discussions | Summary |

<Note>
  CoTel is at an early stage of development. The current version of subscriptions focuses on two main types: events and digests. Subscription functionality will expand based on user feedback and real usage scenarios.
</Note>
