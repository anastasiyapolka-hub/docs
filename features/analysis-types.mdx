CoTel lets you ask questions about the history of any Telegram chat, channel, or group you have access to — or public chats if you are using a CoTel service account. Instead of searching through conversations manually, you simply write a query and receive a structured answer based on specific messages.

Chat requests are available on the workspace page. Query settings and the chat list are located in the left panel, and the result is displayed in the right area.

## How to run a query

<Steps>
  <Step title="Choose a chat">
    In the left panel, in the **Chat requests** section, expand the list of available chats and choose the one you need — a chat, channel, or group. The list is generated automatically from your connected Telegram account.

    If your plan includes request history, the **History** block appears above the list with chats you previously queried — for quick repeat access.

    If you are using a CoTel service account, you need to paste the chat link manually, or choose an existing one from chat history.
  </Step>
  <Step title="Configure settings (optional)" stepNumber={2}>
    Open the **Query settings** block to set:

    - **History analysis period** — how many days of chat history to use (range: 1–60 days, default: 1 day). The maximum available history analysis period depends on your plan.
    - **AI model** — choose a model for this request or leave the default model selected in your profile settings.
  </Step>
  <Step title="Write your query" stepNumber={3}>
    Enter your question in the input field at the bottom of the right side of the screen. The query can be in any language — CoTel will detect it automatically and answer in the same language.
  </Step>
  <Step title="Run the analysis">
    Click the launch button or press Enter. The result will appear in the right workspace area.
  </Step>
</Steps>

## Query settings

### History analysis period

Defines how many days of chat history CoTel reads for each query. It is configured in the **Query settings** block in the left panel.

- Range: 1–60 days
- Default: 1 day

<Info>
  The maximum period available for analysis depends on your plan. The higher the plan, the deeper the history you can access.
</Info>

### AI models

For each query, you can choose one of two models or set a default model in your profile settings.

| Model | Best suited for |
| --- | --- |
| **OpenAI GPT-4.1 mini** | Fast general-purpose analysis of chats of any size |
| **Claude Sonnet 4.6** | Deeper analysis of long discussions where nuance matters |

<Info>
  Claude Sonnet 4.6 is available on paid plans. Free plan users work with GPT-4.1 mini.
</Info>

## How to write queries

CoTel does not require any special syntax — write the way you would ask a real person. The model understands the meaning of the query, accounts for synonyms, abbreviations, and transliteration, and responds in the language of your question.

Example queries:

- “What was discussed this week?”
- “Were there any complaints about delivery?”
- “Who suggested changing the contractor, and when?”
- “What decisions were made about the budget?”
- “Are there any mentions of Ivan in the chat?”

The more specific your question, the more accurate the answer. If you need to cover a longer period, increase the **History analysis period** parameter in the query settings.

## Result

The answer is displayed in the right workspace area of the page. CoTel:

- finds messages relevant to your question by meaning, not only by exact word match;
- groups the answer by topic or chronology, depending on the nature of the question;
- quotes specific messages in the format `@author: “quote”`;
- shows contradictions in the chat when they exist instead of smoothing them over;
- warns you if too few relevant messages were found.

<Warning>
  Request history is not saved: the result of the current query will be replaced by the next one. If you need to keep the answer, copy it before running a new query.
</Warning>

## Data confidentiality

<Warning>
  Analysis is performed by a third-party AI model. Do not use CoTel for requests involving chats that contain secret or confidential data.
</Warning>
