Every time you run an analysis in CoTel, the result is saved to your history. You can access past analyses from the home screen or the history panel in the workspace — no need to re-run a query just to read a previous result. History also lets you export reports and repeat an analysis with a single click to get an updated view of the same chat.

## What is saved in history

Each history item shows:

- **Title** — the name of the chat or channel that was analyzed
- **Analysis type badge** — Summarization, Notes, Search, or Keywords
- **Date** — when the analysis was run
- **Read time or result count** — an estimate of how long the result takes to read (for summaries and notes) or the number of results returned (for search and keyword analyses)

Your most recent analyses appear directly on the home screen for quick access. The full history is available in a scrollable panel.

## Actions on history items

<CardGroup cols={2}>
  <Card title="Repeat" icon="play">
    Re-run the same analysis on the same chat. Useful for getting a fresh summary or updated search results after new messages have been posted.
  </Card>
  <Card title="Export" icon="download">
    Download the analysis result as a PDF file for sharing or offline reference.
  </Card>
</CardGroup>

### Repeat

Clicking **Repeat** on a history item re-runs the original query against the same chat using your current plan's history depth and the AI model configured in your query settings. The new result is added to your history as a separate entry.

### Export

Clicking **Export** downloads the result as a **PDF** file. This is useful for sharing reports with colleagues or archiving results outside of CoTel.

## Removing history items

To remove a result you no longer need, use the **Remove from history** action on any history item. Removing an item deletes it from your history list but does not affect the underlying chat data.

## History analysis depth by plan

How far back CoTel can read during an analysis depends on your plan:

| Plan | Maximum history depth |
|---|---|
| Free | 7 days |
| Basic | 30 days |
| Pro | 90 days |

<Tip>
  If you need to analyze older messages, you can upgrade your plan to increase the history depth available per query.
</Tip>

<Note>
  History and channels list is available on Basic and Pro plans. Free plan users can still view their analysis results but do not get persistent chat and channel history.
</Note>
