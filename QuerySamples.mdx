CoTel helps you work with Telegram chats, channels, and groups as a source of knowledge: instead of manually reading hundreds of messages, you can ask a question in natural language and receive a structured answer based on the discussion history.

This page contains request examples for different scenarios: work chats, technical discussions, news channels, parenting and cooking chats, travel communities, job channels, real estate chats, and other Telegram sources.

Each example shows:

- **Scenario** — where this request may be useful
- **Goal** — what the user wants to find out
- **Example request** — how to phrase the question for CoTel
- **What CoTel returns** — what kind of result you will receive

<Info>
  You can use these examples as ready-made templates: copy a relevant request, replace the topic, period, or object name, and run the analysis in the needed Telegram chat or channel.
</Info>

## Work and project chats

## How to improve the result

The more specific your request is, the more useful the result will be. A good request usually includes:

1. **Goal** — what exactly you want to find out
2. **Period** — how many days or messages of history to review
3. **Topic** — what question, object, product, place, or event you are interested in
4. **Answer format** — list, summary, table, topic groups, arguments for and against

<AccordionGroup>
  <Accordion title="Too broad request">
    “What happened there?”

    This request may produce an overly broad and superficial summary.
  </Accordion>

  <Accordion title="More effective request">
    “Summarize the main decisions, tasks, and open questions from the last 7 days. Split the answer into sections: decisions, tasks, problems, important messages.”

    This request gives CoTel a clear structure and helps return a more useful result.
  </Accordion>
</AccordionGroup>

## What you can do next

After receiving the result, you can:

- refine the question and run the analysis again;
- reduce or increase the history period in query settings;
- use the discovered topics to create a subscription;
- go to the original messages in Telegram if you need to verify the context.

<Note>
  CoTel is at an early stage of development. The current version is focused on two main scenarios: analyzing Telegram chats on request and automated subscriptions. Functionality will be expanded based on user feedback and real use cases.
</Note>
