CoTel helps you work with Telegram chats, channels, and groups as a source of knowledge: instead of rereading hundreds of messages manually, you ask a question in plain language and receive a structured answer based on the discussion history.

This page contains example queries for different scenarios: work chats, technical discussions, news channels, parenting and cooking chats, travel communities, job postings, real estate, and other Telegram sources.

Each example shows:

- **Scenario** — where this query can be useful
- **Task** — what the user wants to find out
- **Example query** — how to phrase the question for CoTel
- **What CoTel returns** — what result you will receive in response

<Info>
  You can use these examples as ready-made templates: copy a suitable query, replace the topic, period, or object name, and run the analysis in the relevant Telegram chat or channel.
</Info>

## How to improve the result

The more specific your query is, the more useful the result will be. A good query usually contains:

1. **Goal** — what exactly you want to find out
2. **Period** — how many days or messages the history should cover
3. **Topic** — which question, object, product, place, or event interests you
4. **Response format** — list, summary, table, topic groups, arguments for and against

<AccordionGroup>
  <Accordion title="Too broad query">
    “What happened there?”

    This query may produce a summary that is too broad and superficial.
  </Accordion>

  <Accordion title="More effective query">
    “Summarize the main decisions, tasks, and open questions from the last 7 days. Split the answer into sections: decisions, tasks, problems, important messages.”

    This query gives CoTel a clear structure and helps return a more useful result.
  </Accordion>
</AccordionGroup>

## What you can do next

After receiving a result, you can:

- clarify the question and run the analysis again;
- reduce or increase the history period in the query settings;
- use the discovered topics to create a subscription;
- open the original messages in Telegram if you need to check the context.

<Note>
  CoTel is at an early stage of development. The current version focuses on two main scenarios: Telegram chat analysis on request and automatic subscriptions. Functionality will expand based on user feedback and real usage scenarios.
</Note>
